# Stable Kingdoms

A browser-based test build of **Stable Kingdoms**.

This repository is ready for GitHub Pages. The game is self-contained in `index.html`, including the portrait assets used by the current Roman/Latin, Byzantine/Greek, and Slavic test kingdoms.

## Play locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
Publish the repository from the `main` branch and repository root (`/`).
